What JARVIS can do

One bot, everything you reach for in a chat.

AI that answers

Ask anything, chat, summarise, translate and more, with several free AI providers behind one command.

Downloaders

Videos and audio from popular sites, sent straight to the chat in good quality.

Image tools

Stickers, resize, compress, convert and fun image effects without leaving WhatsApp.

Games and fun

Quizzes, word games, trivia, jokes, roasts and a virtual coin economy for groups.

Group admin

Anti-spam, welcome messages, polls, reminders and tools that keep big groups tidy.

Everyday utilities

Reminders, calculators, converters, time zones, notes and many small helpers.

Owner dashboard

A live dark dashboard with uptime, usage, recent activity and an AI ops assistant.

Privacy first

Your chats stay on your server. The optional install ping sends counts only, and it is documented.

Get started

Run your own JARVIS in a few minutes.

Get the code

Clone the repository from GitHub and run npm ci. Node.js 20 or newer is needed.

Set your number

Put your WhatsApp number in .env as the owner. Everything else has safe defaults.

Pair and chat

Start the bot, link it as a device with the pairing code, then send /menu.

Open about data

JARVIS never reads your chats for us. An optional anonymous install ping sends only a random id, version, uptime, a one-way number hash, a hosting type and command counts. You can switch it off with TELEMETRY=off. Everything is written down in the README.
